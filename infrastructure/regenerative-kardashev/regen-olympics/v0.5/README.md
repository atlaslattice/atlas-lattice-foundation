# REGEN OLYMPICS v0.5 — Dream Team Evolution

Status: toy systems tournament / hypothesis generator; **not an empirical Earth forecast**.

## Pipeline
1. Randomly generate 5,000 regenerative worlds.
2. Stress all worlds under common conditions.
3. Identify Pareto and specialist champions.
4. Synthesize Dream Team candidates from champion traits.
5. Re-run finalists under common Monte Carlo shocks.
6. Rank on ROI, productive capacity, drain closure, resilience, and collapse avoidance.

## Headline result
The synthesized **Dream Team Best-of** won the championship on composite score. It did not dominate every specialist metric, which is the intended behavior of the tournament architecture.
